# ACE, Aplicativo de Competições Escolares

Controllers -> Concatenam as rotas e métodos para fazer o usuário interagir com a aplicação
Core -> Centro do sistema com Classes importantes que não pertencem a uma categoria
Middleware -> Verificações do sistema que são realizadas durante outras funções
Models -> Apenas código query para o banco de dados
Services -> Controlam e verificam entrada e saída de informações para o banco de dados 
Views -> Telas de interação com o usuário
